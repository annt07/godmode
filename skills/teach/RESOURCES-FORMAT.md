# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Get knowledge for explainers from here, not from parametric guesses. Wisdom comes from the communities in this file.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **High-trust only.** Prefer primary sources, recognised experts, peer-reviewed work, and communities with strong moderation. If a resource is marketing that looks like education, do not include it.
- **Annotate each entry.** A link without a note is useless in three months. Add one line: what it covers and when to use it.
- **Group by Knowledge / Wisdom.** This follows the philosophy in [SKILL.md](./SKILL.md). A resource can be in only one group.
- **Show gaps explicitly.** If no good resource exists for an area that the mission needs, write a `## Gaps` section. List in it what is missing. This guides future searches.
- **Remove without hesitation.** If a resource is wrong, shallow, or off-mission, remove it. Do not hide it. Five sharp sources are better than thirty mediocre ones.
- **Record community preferences.** If the user does not want to join communities, write it here. Then future sessions do not propose them again.
